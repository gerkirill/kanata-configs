# Keyboard Mappings Documentation

## Download

Kanata executable can be downloaded from [here](https://github.com/jtroo/kanata/releases). Or use download.sh script:

```bash
./download.sh
```

## Special Behaviors

- **Tap-Hold Keys**:
  - `caps`: Tap for Caps Lock, hold for Left Ctrl
  - `d`: Tap for D, hold for Left Ctrl
  - `f`: Tap for F, hold for Left Shift
  - `j`: Tap for J, hold for Right Shift
  - `k`: Tap for K, hold for Right Ctrl
  - `Right Alt`: Tap for Enter, hold for Right Alt
  - `Right Ctrl`: Tap for Backspace, hold for Right Ctrl
  - `spc`: Tap for Space, hold for Extra layer

- **Chords**:
  - `w + e`: Esc (when both tapped within 50ms)
  - `i + o`: Backspace (when both tapped within 50ms)

## Extra Layer

| Key       | Function                          |
|-----------|-----------------------------------|
| `h`       | Left Arrow                        |
| `j`       | Down Arrow                        |
| `k`       | Up Arrow                          |
| `l`       | Right Arrow                       |
